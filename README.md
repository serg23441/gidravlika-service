# Гидравлика Сервис / отслеживание-оплаты

Веб-приложение для ведения учёта заказов, отработанных часов механиков, статусов оплат, прикрепления фото актов и планирования задач.

## Быстрый запуск на GitHub Pages
1. Создайте новый репозиторий на GitHub (например, `gidravlika-service`).
2. Загрузите файл `index.html` в корень репозитория.
3. Откройте **Settings** репозитория → вкладка **Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source:** Deploy from a branch
   - **Branch:** `main` (или `master`) / root (`/`)
5. Нажмите **Save**. Через минуту приложение станет доступно по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

## Возможности
- 📋 **Заказы:** учёт часов по сотрудникам, статусы «Хозяйство оплатило» / «Начислено», прикрепление фото актов с просмотром в модальном окне.
- 📌 **Планы:** нумерация строк, отметка важности (🔥 Важное / ⚪ Обычное), статус выполнения (⏳ В работе / ✓ Выполнено), привязка к исполнителям.
- 📊 **Итоги:** сводка по заказам, начислениям и часам, разбивка и сортировка по месяцам, статистика выработки механиков в часах и процентах.
- 💾 **Автосохранение:** сохранение всех данных прямо в вашем браузере (LocalStorage).
- 📥 **Экспорт:** генерация автономных отчетов в формате HTML и файлов Microsoft Excel (.xlsx) без внешних зависимостей.
