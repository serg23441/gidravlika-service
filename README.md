# Гидравлика Сервис

Веб-приложение для ведения заказов и планов с облачной синхронизацией:
- Вход по паролю: 1787
- Заказы с разбивкой по месяцам и хронологической сортировкой
- Планы с компактным интерактивным календарем на 6 месяцев (3х3 см)
- Оптимизированное сжатие фото и отложенная загрузка для быстрой работы на смартфонах
- Выгрузка отчетов в Excel (.xlsx) и автономный HTML с галереей актов
